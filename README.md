# Real-Time Chat Application

## About the Project
This project is a real-time chat application that allows users to communicate instantly. Users can create an account, log in, and participate in conversations with others in real time. The application is designed for seamless, interactive chatting and supports user authentication for secure access.

---

## Key Features
- **User Authentication**: 
  - Create an account with a unique username and password.
  - Secure login functionality to access the chat.
- **Real-Time Messaging**:
  - Instant communication between users.
  - Messages are displayed in real time without the need to refresh the page.
- **Interactive Chat Interface**:
  - A user-friendly and responsive design.
  - Automatically scrolls to the latest messages for a smooth chat experience.

---

## How to Use
### Prerequisites
- A web browser to access the chat application.

### Steps
1. Open the application in your browser (hosted link or local setup).
2. **Create an Account**:
   - Click on the "Sign Up" button.
   - Enter your desired username and password.
3. **Log In**:
   - Use your credentials to log in.
4. **Start Chatting**:
   - Once logged in, you can join a chat and send messages in real time.
